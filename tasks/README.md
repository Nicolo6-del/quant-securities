# 协作协议:研究任务书

本目录是研究任务书,由 Claude(无外网,负责设计与审阅)编写,由**本地 AI/开发者**(有外网和数据权限)执行。执行结果通过 GitHub 回传给 Claude 审阅。

## 研究对象
天山生物(300313.SZ,创业板)作为主要标的,另设对照组。理论基准:Admati & Pfleiderer (1988),均衡公式在分支 `feature/ap-model`(`src/quantsec/theory/admati_pfleiderer.py`)。

## 工作流程
1. 每个任务书对应一个分支 `task/Txx-简称`,从 `master` 切出。
2. 完成后开 PR,标题 `[Txx] 简称`,正文按下面"回传格式"填写。
3. Claude 审阅后在 PR 中评论;需要修改就在同一分支继续提交。
4. 任务书的编号顺序即依赖顺序:T01 → T02/T03/T04 → T05 → T06。

## 硬性规则
- **不要提交行情数据**(`data/` 已在 `.gitignore`)。只提交代码、汇总表(CSV,单个文件 < 1 MB)、图(PNG)和报告(Markdown)。
- **预注册**:T01 开头先提交 `tasks/controls.csv`(对照组名单与选取理由),并在看任何结果前合并。之后不得因结果不理想更换对照组。
- **如实报告**:结果与预期相反、不显著、数据有问题,都要写进报告,不要调参数凑结果。每个检验只跑任务书规定的设定;额外探索必须标注为"探索性"。
- **可复现**:记录数据来源、接口版本、下载时间、随机种子。随机过程固定 seed。
- **不确定就写明**:任务书里标注"待确认"的地方,由你查证后写入报告并给出来源链接,不要猜。
- 代码放 `src/quantsec/`,有对应测试 `tests/`。用合成数据写测试,不依赖网络。

## 回传格式(PR 正文)
```
## 做了什么
## 样本(标的、区间、频率、剔除了哪些日期及数量)
## 主要结果(列出关键数字,指向 results/ 下的文件)
## 与预期不一致或有疑点的地方
## 未完成/需要 Claude 决定的问题
```
结果文件统一放 `results/Txx_*`;报告为 `results/Txx_report.md`。

## 预注册预测(在看数据前写下)
- **P1**:日内成交量曲线不是单一 U 形,而是在 13:00 午休复牌后出现第二个小高峰(W 形)。依据:论文把集中解释为"休市前后"的需求,午休是 A 股特有的休市。
- **P2**:天山生物的"聚集程度"弱于机构持股高的对照组。依据:论文预测机制依赖可选择时间的机构流动性交易者。
- **P3**:按论文假设 3,价格变动方差满足 低量→高量 > 低量→低量 > 高量→低量。
- **P4**:成交量大的时段 Amihud 非流动性更低(市场更深)。
- 以上任一被推翻都是有价值的结果,请如实报告。
